# NodeGraph
- 通用节点编辑器
- 基于UI Toolkit的GraphView
- 数据保存为ScriptableObject
- 节点配置只作为静态使用(所有节点执行器共享 避免复制) 节点执行器保留自己的节点上下文
- 最好能查看节点实时进度 方便测试

## 编辑器
- 网格背景
- 能拖着缩放 单选 框选 连线 删除
- 新增菜单
- 反正传统节点编辑器的通用功能都要有

- 能反馈运行时的执行状态 当前那一节点在执行 等效果

## 节点配置
- 短效节点:单帧内执行完成
- 长效节点:有进度条 不是一帧内能结束

## 节点执行器
- 变量字典:节点内配置变量时使用 运行时通过字符串key从这里获取
