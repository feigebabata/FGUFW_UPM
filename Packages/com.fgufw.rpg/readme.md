## 技能系统
- 对象判空容错
  - 技能被镜像反弹后如何判断施法者
  - 施法者死亡后释放出的持续技能如何继续
  - 技能需要的某属性施法者身上没有
  - 施法者属性快照 避免角色死亡后技能无法继续

- 技能配置
  - 一般是一个链式的节点触发链路
  - 搭配技能编辑器
  - 特殊技能无需强制依赖技能编辑器实现 直接手撸逻辑(特殊逻辑出现三次再考虑生成新节点)

- 技能控制模式
  - 单次释放:最简单的
  - 蓄力式: 有长按效果 
  - 开关式: 会切换技能UI 关闭才会重新进入cd
  - 多段式: 每段不同效果 会切换技能UI 
  - 最好能通过技能配置组合成不同控制模式 同时对ai控制技能要求变高
  - 技能需明确退出节点 包括被中断
  
- 技能释放限制要和控制层分开 需要区分能不能放和想不想放

- 关于变身系统
  - 技能肯定会变
  - buff和数值可能保留

### 技能编辑器
- 基于UI Toolkit的GraphView
- 数据保存为ScriptableObject
- 技能配置只作为静态使用(所有技能共享 避免复制) 角色保留自己的技能上下文
- 最好能查看技能实时进度 方便测试

### Buff
- 配置只作为静态使用(所有Buff共享 避免复制) 角色保留自己的Buff上下文


## 世界系统

### 控制权
- 例如位移控制权
  - 位移终点在不可移动区域
  - 陷阱的坠落位移
  - 受到技能的强制位移

- 如何决定当前受谁控制
  - 不同位移添加控制优先级 执行优先级高的
  - 或者整合位移系统 所有操作推送到系统内处理

### 系统维度
- 位移
- 伤害
- HP
